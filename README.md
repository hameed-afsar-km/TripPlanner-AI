## 🌟 Overview

**TripPlanner AI** is a premium, agentic trip management platform designed for the modern traveler. Powered by **Gemini 2.5 Flash**, it transforms vague ideas into high-fidelity itineraries, manages your travel documents, and provides real-time planning assistance within a stunning **glassmorphic** interface.

---

## ✨ Key Features

- 🤖 **Agentic AI Chat**: Real-time conversation with Gemini 2.5 Flash for personalized trip planning.
- 📂 **Smart Attachments**: Upload tickets, hotel confirmations, and photos directly to your AI assistant.
- 🕰️ **Live History**: Persistent, real-time chat history synced with Firebase Firestore.
- 🎨 **Premium Aesthetics**: High-end dark mode with glassmorphism, glowing orbs, and smooth Framer Motion animations.
- 📍 **Interactive Maps**: (Coming Soon) Seamless integration with MapView for route visualization.
- 🔐 **Secure Auth**: Persistent Google Authentication via Firebase Auth.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Backend**: [Firebase](https://firebase.google.com/) (Auth, Firestore, Storage)
- **AI Model**: [Google Gemini 2.5 Flash](https://ai.google.dev/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/hameed-afsar-km/TripPlanner-AI.git
cd TripPlanner-AI
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env.local` file with the following keys:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_id
GOOGLE_GENERATIVE_AI_API_KEY=your_gemini_key
```

### 4. Run the development server
```bash
npm run dev
```
